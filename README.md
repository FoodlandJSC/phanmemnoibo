# phanmemnoibo — Hệ thống nội bộ Foodland

Phần mềm quản lý nội bộ cho Foodland JSC (mua hàng, bán hàng, kho, quỹ, ngân hàng, báo cáo), thay cho MISA.

Giai đoạn hiện tại: phân tích yêu cầu xong phần lớn, chuẩn bị dựng Frontend (React + TypeScript, Ant Design, AG Grid, monorepo pnpm).

Tài liệu nằm trong thư mục [`docs/`](docs/). Bắt đầu từ [`docs/ROADMAP.md`](docs/ROADMAP.md). Hướng dẫn cho Claude Code: [`CLAUDE.md`](CLAUDE.md).
